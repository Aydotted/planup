Step 36C Visibility Strategy
PlanUp uses a Hybrid Future Visibility Model.

Recurring items are stored as master entities.

Future occurrences are generated within defined planning windows:

Tasks: 90 Days

Schedule Items: 365 Days

Shifts: 180 Days

Users can:

View future workload
Plan holidays
Analyse shift patterns
Forecast recovery
View future reminders
Future occurrences remain linked to:

recurrenceSeriesId

Future versions will support:

Edit occurrence
Edit series
Delete occurrence
Delete series
Skip occurrence
Recovery-aware recurrence
Burnout-aware recurrence
