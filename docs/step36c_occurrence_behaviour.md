Step 36C Occurrence Behaviour
Recurring Tasks are stored as a master task.

Future occurrences are virtual occurrences generated by the recurrence engine.

A recurring task should appear:

Home Screen
Calendar
Daily Agenda
Dashboard
without permanently storing all occurrences.

Benefits:

Reduces database size
Improves performance
Simplifies editing
Simplifies deletion
Supports forecasting
Supports burnout modelling
Supports recovery intelligence
Future Features:

Edit occurrence
Edit series
Skip occurrence
Delete series
Recovery-aware recurrence
