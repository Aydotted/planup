Recurrence Generation Strategy
PlanUp will use Hybrid Recurrence Generation.

Recurring entities are stored once as a parent recurrence series.

Occurrences are generated only when needed.

Benefits:

Smaller database
Better performance
Easier editing
Easier deletion
Supports future forecasting
Examples:

Calendar View → Generate visible occurrences

Agenda View → Generate upcoming occurrences

Dashboard → Generate active occurrences

Future:

Recovery Engine Burnout Engine Forecast Engine

will consume recurrence data directly.
